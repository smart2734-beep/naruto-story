# 결을 잇는 자 — 모바일 2D 닌자 RPG 첫 기획서

버전: 0.1 / 작성일: 2026-10-10

상태: 구현 전 설계안. 코드, 완성된 아트, 플레이 테스트 결과를 포함하지 않는다. 모든 레벨, 시간, 비용, 효과 수치와 평가 기준은 초기 가설이며 실제 모바일 플레이로 조정해야 한다. 이름은 가제로, 상표와 명칭의 별도 검토가 필요하다.

## 1. 한 문장 소개와 핵심 매력

**장비로 변신하는 영물과 계약한 수습 닌자가, 끊어진 교역로를 복구하며 여섯 나라가 감춰 온 계약의 진실을 찾아가는 모바일 2D 액션 RPG.**

가제는 **《결을 잇는 자》**. 플레이어는 혈족과 직업을 별도로 선택한다. 출신은 능력을 사용하는 한 가지 방식이고, 직업은 훈련으로 익히는 전투 방식이다. 혈계가 없는 출신도 선택할 수 있다.

게임을 대표하는 장면은 작은 영물이 플레이어의 발치에서 사라져 신발의 무늬가 되는 순간이다. 동행할 때는 숨은 길을 찾아주던 친구가, 신발일 때는 절벽을 넘어갈 마지막 한 걸음을 만들어준다. 이후 검·망토·장갑으로 변하는 친구들과 조합을 바꾸며 새로운 지역을 탐험한다.

핵심 재미는 다음과 같이 연결된다.

| 재미 | 플레이어가 실제로 하는 일 | 다음 행동으로 이어지는 이유 |
| --- | --- | --- |
| 성장 | 임무로 기술을 배우고 전직 시험을 통과한다 | 같은 적도 다른 전투 방식으로 상대한다 |
| 수집 | 도안·재료·영물의 흔적을 발견한다 | 새로운 장비 특성과 계약 퀘스트가 열린다 |
| 선택 | 영물을 동행시킬지 장비로 바꿀지 결정한다 | 탐색·방어·공격 중 현재 필요한 능력을 고른다 |
| 모험 | 다른 나라의 지형과 생활을 경험한다 | 문화와 환경에 따라 임무 해결법이 달라진다 |
| 관계 | 동료의 부탁과 영물의 계약 약속을 지킨다 | 개인 이야기와 변신의 다른 운용 방식이 열린다 |

## 2. 모바일에서 반복하는 플레이 흐름

### 기본 조작

- 세로 화면의 2D 탑다운 시점. 캐릭터 기준 약 8~10타일 너비의 전투 공간을 우선 검토한다.
- 왼쪽 아래 이동 패드, 오른쪽 아래 회피와 스킬 버튼. 기본 공격은 사거리 내 적에게 자동 실행하며 수동 설정도 제공한다.
- 처음에는 이동·기본 공격·회피만 사용하고 Q1 완료 시 직업 스킬 1개를 배운다. 이후 직업 스킬 2개와 혈계 또는 도구 스킬 1개까지 장착한다. 영물의 효과는 회피·공격·상호작용에 연동해 별도 전투 버튼을 늘리지 않는다.
- 영물 초상화를 눌러 동행/장비 상태를 전환한다. 변신 중 위험을 볼 수 있도록 전투 화면을 가리지 않는다.
- 적의 공격은 색뿐 아니라 바닥 모양, 방향, 준비 동작으로 예고한다. 중요 효과가 겹치면 적의 공격 예고를 우선 표시한다.
- 자동 이동은 발견한 안전 경로에서 제공한다. 자동 반복 사냥은 직접 완료한 일반 필드에서만 제공하며, 보스·잠입·선택 장면은 수동으로 진행한다.
- 첫 버전은 오프라인 싱글플레이와 로컬 저장을 기준으로 한다. 장기 서비스 구조는 이후 별도 결정한다.

### 한 번의 플레이

`마을에서 1개 임무 선택 → 3~5분 탐색/전투 → 재료·관계 변화 확인 → 제작 또는 기술 선택 → 다음 지역의 단서 발견`

주요 던전은 정식 버전에서 10~15분을 목표로 한다. 첫 시제품의 던전은 5~8분으로 줄여 핵심 행동을 빨리 검증한다. 이동 시간만 늘려 목표 시간을 맞추지 않는다.

예시: 습지에서 끈 재료를 모으는 동안 신발 영물로 물웅덩이를 넘는다. 도착한 창고에서는 영물을 동행으로 되돌려 진짜 물품의 냄새를 찾는다. 가져온 재료로 검 손잡이를 바꾸면 다음 임무에서 회피 직후 공격이 강화된다.

## 3. 세계관과 6개 지역

### 세계: 오르새

젖은 목재, 빛나는 광물, 천으로 만든 통행 표식, 낡은 수로가 공존하는 세계다. 픽셀 아트에서는 지역의 실루엣과 바닥 재질을 구분하고, 국가는 복식과 건축의 차이로 표현한다. 닌자들이 모두 같은 유니폼이나 머리 장식을 사용하지 않는다.

사물은 반복해서 닿고 사용되며 **결**을 남긴다. 결은 접촉과 힘의 전달이 남긴 물리적 흔적이다. 사용자는 자신의 호흡과 도구를 통해 결에 작용할 수 있다. 결은 죽은 사람의 영혼이나 완전한 과거 영상이 아니다.

결을 다루는 기술은 실제 매개물이 필요하다. 밧줄 없이 매듭을 만들거나, 존재하지 않는 금속을 진동시키거나, 아무 물질도 없이 무게를 옮길 수 없다. 닿거나 짧은 거리에 있는 대상만 조작하며, 날씨와 재질에 영향을 받는다.

전투 자원 **결력**은 호흡과 집중력의 게임상 표현이다. 초기안은 최대 100, 기본 기술 비용 8~25, 행동이 없을 때 초당 6 회복이다. 고갈되면 관련 기술을 사용할 수 없지만 이동·기본 공격·일반 회피는 가능하다. 영물의 능동 효과도 같은 자원을 쓴다. 별도 게이지를 계속 추가하지 않는다.

**혈계**는 특정 매질에 민감한 유전적 감각이다. **공통 기술**은 도구와 훈련으로 익히는 결 조작이다. 혈계 사용자는 특화된 감각과 고유 기술을 얻고, 혈계 없는 사용자는 같은 활성 슬롯에 도구 기술을 장착한다. 혈계는 종합 능력치의 상위 등급이 아니다.

### 닌자의 사회적 역할

이 세계의 닌자는 잠입·추적·호위·정밀한 결 조작을 훈련한 전문 임무 수행자다. 민간 조직 **길잇기 조합**은 분쟁 지역의 우편, 수로 정비, 영물 중재, 실종자 구조를 맡는다. 국가에 고용된 닌자도 있지만 모든 닌자가 군인은 아니다.

플레이어는 변경 마을 **이음터**의 조합 견습생이다. 혈계가 없는 선배 **단우**가 첫 교관이다. 단우는 경험과 도구만으로 활약하며, 플레이어를 특정 혈족의 구원자로 취급하지 않는다.

### 여섯 나라와 도시권

| 지역 | 생활·시각적 특징 | 원하는 것 / 두려워하는 것 | 탐험·임무와 자원 |
| --- | --- | --- | --- |
| **물굽이 연합** | 수상 장터, 벼농사, 수로 도시들의 느슨한 연합. 이음터가 속한다 | 안정된 물 공급 / 상류의 독점과 범람 | 수로 복구·호위. 수초섬유, 하천광, 수문 도안 |
| **사다리령** | 절벽에 걸린 계단과 운반 승강기, 공동 운송 노동조합 | 안전한 운송과 자치 / 외부의 통행료 장악 | 고도차 추적·화물 균형 퍼즐. 닻석, 강한 끈 |
| **누림 습국** | 발효 식품과 약초 정원, 낮은 나무집, 습지 공동체 | 생태 순환과 약재 교역 / 무분별한 채취와 강제 규격화 | 해독·채집·영물 중재. 균사포, 수지, 약재 |
| **철울 공방국** | 진동으로 작동하는 기계, 낮은 광산, 거대한 공방 | 공방의 생존과 수주 / 기계 공명 사고와 기술 유출 | 제작·기계 진압. 청동편, 진동판, 장갑 도안 |
| **백지 기록령** | 바람막이 회랑과 도자기 기록판, 마른 고원 | 기록의 신뢰와 국경 안정 / 과거의 조작이 공개되는 것 | 조사·문서 대조·잠입. 기록토, 안료, 도자기 부품 |
| **유리해 항맹** | 얕은 바다와 유리질 산호, 반사판을 쓰는 항구 도시들 | 자유로운 항로와 거래 / 항로 단절과 중앙 통제 | 항해 준비·빛 퍼즐·협상. 해염, 유리편, 망토 도안 |

각 지역을 하나의 혈족이 통치하지 않는다. 여러 혈족과 혈계 없는 주민이 함께 살며, 국가 안에도 반대 의견이 있다.

### 세력과 역사

- **길잇기 조합:** 길과 계약을 복구해 주민을 보호하려 한다. 중립을 유지하느라 피해자의 요구에 늦게 응답하는 문제가 있다.
- **통행금고:** 교역을 보증하는 민간 금융·물류 조직. 분쟁 없는 통행을 원하지만, 전쟁과 장애가 늘어나자 통행권 독점을 추진한다.
- **철울 공방연회:** 기술자의 안전과 수주가 중요하다. 통행금고의 대규모 주문에 의존하는 공방과 반대하는 공방으로 갈린다.
- **영물 모임 ‘빈 가지’:** 서식지와 자발적 계약을 지키려 한다. 영물마다 인간과 협력할지에 대한 의견이 다르다.
- **백지의 기록관:** 과거를 보존해야 하지만 국가가 조작한 문서까지 진실로 인증해 온 책임이 있다.

42년 전, 폭우와 전쟁 속에서 주요 교역로가 동시에 멈춘 **단절년**이 있었다. 여섯 지역은 결 전달망을 표준화한 **통행약정**을 만들었다. 공식 기록은 이를 기술 혁신으로 설명한다.

실제로 전달망의 핵심에는 영물들의 갱신 가능한 동의 계약이 있다. 당시 권력자들은 갱신 조항을 숨기고 자동 연장으로 바꿨다. 지금 발생하는 수문 오작동과 교역로 이상은 영물들이 이의를 제기하는 과정에서 나타난다. 위험해진 것은 인간과 영물 모두에게 현실적인 문제다.

통행금고 책임자 **류담**은 혈계 없는 전직 구조 닌자다. 단절년의 피해를 겪은 그는 동의 갱신을 없애고 결 전달망을 중앙 장치에 영구 고정하려 한다. 사람을 살리려는 동기는 이해할 수 있지만 강제 계약, 노동자 억류, 피해 은폐에 책임이 있다.

최종 목표는 장치를 부수는 것만으로 끝나지 않는다. 주민을 대피시키고, 제한된 수동 수로를 확보한 뒤, 영물과 지역별 계약을 다시 체결한다. 결말에서도 운송 지연과 복구 비용은 남는다.

## 4. 혈계 집단 10개와 대표 캐릭터

첫 정식 설계에서는 모두 인간 혈족으로 구성한다. 능력 때문에 다른 종으로 규정하거나 도덕·성격을 유전으로 설명하지 않는다. 혈계 기술은 공통적으로 결력을 소비하며 아래의 추가 조건을 가진다.

### 혈족의 능력과 문화

| 혈족 | 기원·생활·가치관 | 혈계 원리와 전투 / 비전투 활용 | 대가와 공략 가능한 약점 | 다른 집단과의 관계 |
| --- | --- | --- | --- | --- |
| **감김족** | 옛 수문 밧줄 관리인. 약속은 다시 풀 수 있어야 한다는 문화 | 손끝으로 섬유의 장력을 감지. 준비한 끈으로 적의 이동 제한 / 구조용 매듭과 하중 검사 | 끈과 고정점 필요. 날카로운 공격으로 끊기며 손이 묶이면 조작 불가 | 접음족과 구조 작업 협력, 저울족과 안전 기준 논쟁 |
| **울림족** | 갱도 구조대의 후손. 말보다 먼저 주변을 듣는다 | 발과 손으로 고체의 진동을 구분. 공격 준비 감지·짧은 충격 / 빈 공간과 붕괴 징후 탐지 | 연결된 단단한 표면 필요. 모래·부유 발판·동시 진동에 약하고 사용 후 어지럼 | 청동족과 공동 장비 제작, 소음 많은 공방 운영에는 반대 |
| **저울족** | 절벽 화물 운반인. 빚과 책임도 무게처럼 기록 | 두 물체 사이의 하중을 잠시 재분배. 자신의 장비를 가볍게 하고 닻을 무겁게 / 승강기 균형 조절 | 총무게 보존, 연결 표식 2개 필요. 생체 내부나 적 신체의 무게는 직접 조작 불가 | 감김족에 장비 의존, 소금족과 운송 계약 경쟁 |

| **첫 30분** | 레벨 4~6, 마을의 수문 사고 해결 시작. 도톰 계약과 줄비 체험 | 직업 스킬 2개, 영물 1개 활성, 첫 제작·+1 강화. 혈계 능력은 짧게 예고 |
| **첫 2시간** | 레벨 8 전후, 1장 마무리와 첫 지역 여행 준비 | 레벨 8에 기본 기술 세 번째 선택지와 혈계/도구 활성 기술, 영물 2종 보유, 장비 특성 선택 |
| **첫 10시간** | 레벨 16~20, 사다리령과 누림 탐험 | 영물 활성 2칸, 유대 이야기, 재료 교환, 전직 시험 접근 또는 완료 |

위 시간은 평균적인 첫 플레이의 목표이며 확정 획득 시간이 아니다. 1장 대표 임무는 첫 30~40분에 체험 가능하게 하고, 2시간 구간에는 추가 조사·수련·선택 임무를 포함한다. 짧은 플레이를 선호하는 이용자에게 반복 사냥을 강제해 시간을 맞추지 않는다.

## 6. 영물 8종과 장비 변신 규칙

### 공통 규칙

1. 영물은 결에 반응하는 독립 생물이다. 포획 확률 뽑기 대신 퀘스트와 상호 동의로 계약한다.
2. 레벨 1부터 활성 영물 1개, 레벨 12의 2장 임무로 2개를 사용한다. 나머지는 숙소에서 쉬고 전투 보너스를 주지 않는다.
3. 활성 영물 하나는 **동행 또는 장비 변신 중 한 상태**만 가진다. 장비 상태의 영물은 동행 탐지·공격·회복을 제공하지 않는다.
4. 두 영물을 모두 장비로 쓰거나, 동행 하나와 장비 하나로 쓰거나, 모두 동행시킬 수 있다. 동일 장비 부위에는 하나만 변신한다.
5. 전투 변신은 2초 준비, 피격 시 취소, 성공 후 해당 영물에 10초 전환 대기시간을 적용한다. 준비 중 움직일 수 없지만 취소와 회피는 가능하다. 비전투에서는 즉시 변신한다.
6. 변신 자체는 결력을 소비하지 않는다. 강한 효과가 발동할 때만 비용을 지불하며 비용과 대기시간을 표시한다. 결력이 부족하면 기본 장비 보너스만 유지한다.
7. 영물은 제작 장비의 해당 부위에 **겹쳐 변신**한다. 제작 장비의 기본 성능과 특성은 유지하고, 영물이 고유 효과를 추가한다. 무기 영물도 원직업의 무기를 대체하지 않고 칼날·장식·날개 등으로 맞춰 붙는다.
8. 영물 보너스는 동일 항목에서 덧셈 계산하고 상한을 둔다. 초기 상한 예시는 이동속도 +15%, 재사용시간 감소 20%. 서로 다른 효과도 무한 반복 발동하지 못한다.
9. 유대는 **낯섦 → 신뢰 → 동행 → 합의** 네 단계. 계약 이야기와 실제 협력으로 발전한다. 상위 단계의 보상은 외형과 효과의 운용 선택이며, 모든 상황에서 더 강한 상위 개체가 되지 않는다.
10. 계약을 어기면 관련 개인 퀘스트에서 반응과 회복 대화가 생긴다. 밥을 놓쳤다는 이유로 영물이 죽거나 구매한 능력이 사라지는 식의 처벌은 없다. 영물을 강화 재료·합성 재료로 소모하지 않는다.

### 영물 목록

아래 수치는 초기 실험값이다. 동행 효과의 자동 발동도 범위와 대기시간을 가지며 상시 무제한 제공하지 않는다.

#### 1) 도톰 — 신발

- **외형·성격·서식지:** 이끼색 털과 여섯 개의 작은 발을 가진 둥근 들짐승. 겁이 많지만 길 기억력이 좋다. 이음터 수로 둑에 산다.
- **만남·계약:** 「젖은 둑의 작은 발」에서 둥지를 안전한 둑으로 옮긴다. 안전한 귀환 경로를 함께 확인하는 것이 계약 조건이다.
- **동행:** 근처의 약한 바닥과 숨은 발판을 표시한다. 전투에서는 적의 돌진 경로를 한 번 알린다.
- **변신:** 발등에 이끼 무늬가 있는 신발. 이동속도 +5%. 회피 후 추가 한 걸음으로 짧은 틈을 넘는다.
- **조건·비용·약점:** 추가 한 걸음은 결력 10, 8초 대기. 넓은 협곡·벽·깊은 물은 건너지 못하고 공중에서는 연속 발동 불가.
- **유대·이야기:** 발자국 무늬가 늘고 발끝에 작은 잎이 생긴다. 거리 증가와 착지 안정 중 하나를 선택한다. 단절년 이후 도톰의 가족이 돌아오지 못한 둑을 찾아준다.

#### 2) 줄비 — 무기 장식/검

- **외형·성격·서식지:** 얇은 비늘이 접힌 긴 몸과 두 앞발을 가진 영물. 장난을 좋아하지만 남의 도구를 망가뜨리는 것은 싫어한다. 오래된 방직소와 물레방아에 산다.
- **만남·계약:** 「방앗간의 헐거운 이음」에서 잘못 묶인 통행 고리를 풀어준다. 사람과 영물 모두에게 맞는 도구를 함께 수선한다.
- **동행:** 걸린 연결쇠를 찾아 작동 방향을 표시한다. 전투에서는 주기적으로 적에게 작은 균형 손상을 준다.
- **변신:** 검에서는 얇은 겹날, 활에서는 탄성 띠, 조율봉에서는 끝날로 변한다. 기본 공격 피해 +4%. 회피 직후 첫 공격이 짧은 파동을 만든다.
- **조건·비용·약점:** 2초 안에 공격해야 발동. 결력 15, 6초 대기. 직선형 파동은 측면을 못 맞추며 피격 경직으로 기회가 사라진다.
- **유대·이야기:** 몸과 무기에 수선 무늬가 생긴다. 파동 폭과 파동 거리 중 선택한다. 자신이 수선한 운반 도구가 강제 계약에 사용됐다는 사실을 알고 용도를 되찾으려 한다.

#### 3) 품새 — 망토

- **외형·성격·서식지:** 넓은 귀가 천처럼 펼쳐지는 작은 나무짐승. 잔소리가 많고 어린 생물을 보호한다. 누림의 나무 쉼터에 산다.
- **만남·계약:** 「두 마리의 귀가」에서 다친 새끼를 적이 없는 길로 호위. 앞으로 휴식 공간을 남겨두기로 약속한다.
- **동행:** 15초마다 근처 아군 한 명에게 작은 보호막을 준다. 솔로에서는 플레이어 또는 호위 NPC를 선택한다.
- **변신:** 어깨를 감싸는 망토, 방어력 +5%. 공격 방향을 향해 멈췄을 때 첫 타격 일부 흡수.
- **조건·비용·약점:** 0.5초 정지, 결력 12, 10초 대기. 후방 공격과 지속 지형 피해에는 발동하지 않음.
- **유대·이야기:** 망토 안쪽에 가족 무늬가 나타난다. 흡수량 또는 호위 대상과 나누기 선택. 모든 새끼를 지키려다 자신의 휴식을 잊은 품새의 이야기를 다룬다.

#### 4) 톡각 — 장갑

- **외형·성격·서식지:** 유리질 마디와 네 집게를 가진 손바닥 크기 영물. 정확한 박자를 좋아한다. 철울의 폐기 공방에 산다.
- **만남·계약:** 「맞지 않는 네 번째 박자」에서 작업기 진동을 안전하게 조율. 깨끗한 조율판을 마련한다.
- **동행:** 금속 적이나 장치의 취약점을 잠깐 표시한다.
- **변신:** 마디가 움직이는 장갑, 장치 상호작용 시간 -10%. 적의 예고가 끝나기 직전 맞춘 공격에 경직 피해 추가.
- **조건·비용·약점:** 정확한 반격 타이밍, 결력 12, 8초 대기. 생물 표적은 추가 효과 절반, 연타로는 발동 불가.
- **유대·이야기:** 마디의 색이 박자에 맞춰 바뀐다. 타이밍 여유와 경직량 중 선택. 동료가 고장 부품으로 분류된 기록을 지우는 대신 바로잡으려 한다.

#### 5) 먹나 — 망토

- **외형·성격·서식지:** 먼지 같은 날개와 작은 돌 눈을 가진 야행성 영물. 낯을 가리며 사생활을 중요하게 여긴다. 백지의 버려진 기록창고에 산다.
- **만남·계약:** 「읽지 않을 편지」에서 개인 편지의 내용을 열어보지 않고 주인에게 돌려준다.
- **동행:** 최근 지나간 적의 이동 방향을 표시한다. 잠입에서는 시선 방향을 강조한다.
- **변신:** 무광의 먼지 무늬 망토. 비전투 탐지 거리 -10%, 회피 뒤 1초 동안 적의 자동 추적을 해제.
- **조건·비용·약점:** 추적 해제는 결력 15, 10초 대기. 투명화가 아니며 범위 공격·이미 발사된 탄·보스의 지정 공격은 피하지 못함.
- **유대·이야기:** 먼지 무늬가 점차 글씨의 빈칸처럼 보인다. 잠입 효율과 회피 후 재배치 중 선택. 먹나가 지운 기록 때문에 피해자가 증언하지 못했다는 일을 바로잡는다.

#### 6) 물숨 — 목걸이

- **외형·성격·서식지:** 투명한 목주머니와 물방울 더듬이를 가진 납작한 수생 영물. 느긋하고 작은 변화에 민감하다. 누림의 정수 웅덩이에 산다.
- **만남·계약:** 「아래쪽 물도 마신다」에서 배양 폐수를 여과. 상류만 깨끗하게 만드는 해결법을 거부해야 계약 가능.
- **동행:** 중독 누적을 일정 간격으로 낮추고 오염된 물을 표시한다.
- **변신:** 작은 물주머니 목걸이, 상태 이상 지속시간 -8%. 마지막 스킬 사용 후 3초 쉬면 결력 소량 회복.
- **조건·비용·약점:** 회복은 12초 대기, 직접 결력 비용 없음. 회복 중 공격 기술 사용 시 취소, 결력 최대치 초과 불가. 폭발 피해를 막아주지 않음.
- **유대·이야기:** 목주머니에 정화한 지역의 색이 층으로 남는다. 회복과 해독 중 선택. 물숨은 가장 깨끗한 연못보다 누가 하류를 돌보는지 기억한다.

#### 7) 담틀 — 허리띠

- **외형·성격·서식지:** 현무암 같은 껍질과 짧은 돌기 발을 가진 영물. 고집이 세고 정해진 길을 선호한다. 사다리령 승강기 주변에 산다.
- **만남·계약:** 「돌아갈 무게」에서 무너지는 화물 승강기에 대체 지지대를 놓는다. 자신에게 모든 하중을 맡기지 않는 것이 조건.
- **동행:** 짧은 시간 적 한 마리의 진로를 가로막는다. 보스는 막지 못하고 준비 동작만 늦춘다.
- **변신:** 납작한 돌 판이 이어진 허리띠, 밀려나는 거리 -15%. 제자리 방어 성공 시 작은 안정 지대 생성.
- **조건·비용·약점:** 결력 15, 12초 대기, 지대 3초. 이동하면 사라지며 원거리 화력은 차단하지 못함.
- **유대·이야기:** 껍질 사이의 수선 자국이 허리띠에도 남는다. 지대 범위와 유지시간 중 선택. 자신만 버티면 된다는 생각에서 도움을 받는 쪽으로 성장한다.

#### 8) 눈솔 — 모자

- **외형·성격·서식지:** 반투명 볏이 빛을 빗질하는 작은 해안 새. 자랑을 좋아하고 길을 자주 착각한다. 유리해의 낮은 등대에 산다.
- **만남·계약:** 「잘못 비춘 항구」에서 반사판을 수정해 작은 배를 안내. 지도 없이 추측한 길을 사실로 말하지 않기로 약속한다.
- **동행:** 가까운 높은 지점에서 숨은 상호작용물을 표시한다. 전투에서는 엄폐 뒤 적의 위치만 알리고 공격하지 않는다.
- **변신:** 반투명 볏 장식 모자, 표식 지속시간 +10%. 첫 표식에 짧은 약점 노출.
- **조건·비용·약점:** 직접 시야 확보, 결력 10, 10초 대기. 안개·차광막에서는 추가 효과 불가, 벽 너머 공격 허용 안 함.
- **유대·이야기:** 볏에 올바르게 안내한 항로의 선이 생긴다. 탐색 범위와 표식 안정 중 선택. 실수를 숨겨 배를 잃게 한 과거를 인정하고 새 항로를 기록한다.

### 선택의 실제 예

도톰을 동행시키면 안전한 발판을 알 수 있지만 긴 회피는 못 한다. 먼저 길을 확인한 뒤 신발로 바꾸면 건너갈 수 있다. 전투에서는 줄비의 공격 보너스를 쓸지, 동행 상태로 적의 균형을 무너뜨릴지 고른다. 후반 두 칸이 열리면 도톰 신발과 줄비 무기를 함께 쓰는 대신 동행 탐지 능력을 둘 다 포기한다.

## 7. 제작과 강화

### 장비 구조

장비 부위는 무기·상의·신발·망토·장갑·장신구. 장신구는 목걸이·허리띠·모자 중 하나를 선택해 장착한다. 영물의 변신 부위도 이 구조에 맞춘다. 모든 부위에 영물이 필요한 것은 아니다.

등급은 **실용 → 정련 → 명품** 세 단계. 명품은 무조건 더 높은 숫자가 아니라 추가 특성 선택이 있는 장비다. 초기안에서 강화는 +0~+5, 실패와 파괴 없이 확정 성공한다. 재료와 재화가 단계별로 증가한다. 장비당 주요 특성은 1개이며 장인에게 비용을 지불하고 재조정할 수 있다.

제작 장비는 기본 능력과 특성을, 영물은 상황별 행동 효과를 제공한다. 예를 들어 **물길 장도**의 ‘회피 직후 공격 시 결력 3 회복’과 줄비의 ‘회피 직후 파동’은 같이 작동하지만 회복에는 6초 대기시간이 있어 무한 순환하지 않는다.

### 재료와 소비처

| 공급처 | 얻는 재료·도안 | 소비처 / 돌아갈 이유 |
| --- | --- | --- |
| 물굽이의 수초·철부리새·수문 폐기물 | 수초섬유, 떨어진 깃, 하천광, 물길 장도 도안 | 기본 무기·신발과 회피 특성. 후반에도 방수 섬유의 원재료 |
| 사다리령 채석·운반 임무 | 닻석, 강한 끈, 허리띠 도안 | 밀림 저항과 호위 장비. 고급 운반 계약으로 재료 교환 |
| 누림의 합의된 채집·생태 관리 | 균사포, 수지, 약재 | 회복 소모품·망토·오염 저항 특성. 계절별 약재 의뢰 |
| 철울 기계 해체·공방 보스 | 청동편, 진동판, 조율 핵, 장갑 도안 | 반격·장치 특성. 특정 파손품을 수선하면 보너스 교환 |
| 백지 기록 복원 | 기록토, 안료, 여과기 도안 | 잠입·표식 유지 장비. 발견한 기록을 가져오면 도안 확장 |
| 유리해 항로 복구 | 해염, 유리편, 항해 망토 도안 | 상태 이상 대응·탐색 특성. 각지 물품의 합리적 교환 |

영물의 몸과 계약한 개체는 제작 재료가 아니다. 야생 적의 전리품도 무조건 가죽·뼈로 통일하지 않는다. 떨어진 깃, 탈피 껍질, 기계 부품과 임무 보상 재료를 사용한다.

장인 관계는 호감도 수치 노가다 대신 의뢰 완료로 도안과 특성 선택을 연다. 재료가 다른 지역으로 이어지지만 진행에 필요한 핵심 재료를 낮은 확률의 단일 드롭에 묶지 않는다. 보스 재료는 첫 완료 보상과 누적 교환으로도 얻는다.

**첫 제작 가설:** 수초섬유 3 + 하천광 2 + 재화 30으로 물길 장도 제작. +1 강화는 하천광 2 + 재화 20. 퀘스트 4에서 필요한 수량을 확정 지급하고, 이후 탐험으로 다른 특성을 제작한다.

## 8. 메인 이야기 5개 장

선택은 각 장의 평판, 주민 반응, 일부 보상과 지원 NPC를 바꾼다. 장마다 중요한 선택은 1개로 제한하고 다음 장의 큰 진행 지점은 공유한다. 최종 복구 장면에 누가 참여하는지로 누적 선택을 반영한다.

### 1장 — 돌아오지 않는 물

- **지역·레벨 가설:** 물굽이 연합의 이음터, 1~8.
- **목표:** 수문 사고를 해결하고 견습 임무를 마친다.
- **주요 인물:** 단우, 매듭, 장인 도겸의 현지 작업장, 도톰, 줄비. 통행금고의 운송 인장이 처음 등장한다.
- **시작:** 평범한 부품 배달 중 수문이 갑자기 역류한다.
- **전개:** 주민의 수리 실패를 조사하다 영물의 서식지가 사라진 흔적을 발견한다.
- **절정:** 물레방아 아래에서 오작동하는 정비기를 멈추고 노동자를 구한다.
- **결과:** 물길은 복구되지만 정상 부품에 덧씌운 계약 고리를 발견한다. 조합은 견습에게 다른 지역의 운송 기록을 확인할 임무를 준다.
- **대표 퀘스트 3개:** 「물보다 먼저 도착해야」 배달·전투 / 「젖은 둑의 작은 발」 구조·계약 / 「물을 돌려놓는 손」 던전·정비.
- **보스:** 정비기 **거름집게**. 직선 집게, 바닥 쓸기, 물길 방출. 이동과 수문 조작을 함께 사용한다.
- **개방:** 영물 1칸, 제작·강화, 혈계 또는 도구 기술, 직업 기술 선택.
- **선택·다음 단서:** 계약 고리를 조합에 맡길지 주민 대표와 공동 보관할지 선택. 다음 장에서 증언하는 NPC가 바뀌며, 고리의 납품처는 두 선택 모두 사다리령으로 이어진다.

### 2장 — 사다리의 통행료

- **지역·레벨 가설:** 사다리령, 9~16.
- **목표:** 끊긴 승강기 노선과 조작된 운송 기록을 조사한다.
- **주요 인물:** 석오, 소리, 세림, 담틀, 통행금고 징수대.
- **시작:** 같은 길에서 통행료가 두 번 청구되고 식량 운송이 멈춘다.
- **전개:** 화물의 무게와 장부를 대조해 징수대가 장애를 이용해 독점 계약을 강요한 사실을 알아낸다.
- **절정:** 폭풍 속 승강기에서 식량과 주민을 내려보내며 무장 운반기를 제압한다.
- **결과:** 지역이 대체 운송 협약을 만든다. 징수대의 위조 기록에는 습국 영물의 결 표본이 사용됐다.
- **대표 퀘스트 3개:** 「상자 두 개의 무게」 균형 퍼즐 / 「빈 화물의 소리」 조사·추적 / 「누구의 길인가」 협상·호위.
- **핵심 도전:** 승강기 위의 **닻 운반기**. 적의 밀침에 대응하고 화물 하중을 맞춘다.
- **개방:** 레벨 12에 영물 활성 2칸, 담틀 계약, 지역 재료 교환.
- **선택·다음 단서:** 노동조합과 상인연합 중 임시 통행 관리자를 선택. 가격 보상 또는 구조 지원이 달라지며, 표본의 원산지는 누림으로 확인된다.

### 3장 — 익지 않은 약속

- **지역·레벨 가설:** 누림 습국과 철울 공방국, 17~24.
- **목표:** 약재 오염을 해결하고 강제 계약용 장치의 제작 경로를 찾는다.
- **주요 인물:** 담이, 아람, 도겸, 품새, 물숨, 톡각. 류담이 처음 직접 제안을 한다.
- **시작:** 새 정수 장치 설치 뒤 하류에서 약재와 영물이 동시에 아프기 시작한다.
- **전개:** 장치는 상류 오염을 없애는 대신 하류로 옮긴다. 공방 기술자는 결 표본의 출처를 몰랐다고 주장한다.
- **절정:** 오염 시설에서 약사를 호위하고, 공방의 공명 장치를 안전 순서로 정지한다.
- **결과:** 공방의 납품 명세서와 숨겨진 계약 도면을 확보한다. 도겸은 자신의 작업장이 문제에 가담한 사실을 인정한다.
- **대표 퀘스트 3개:** 「아직 익지 않은 약」 호위 / 「아래쪽 물도 마신다」 정화 퍼즐·영물 중재 / 「맞지 않는 네 번째 박자」 제작·장치 제압.
- **보스:** **세 박자 조율탑**. 세 재질의 파동을 보고 안전한 고정점을 선택한다. 단순 피해 누적만으로 파괴할 수 없다.
- **개방:** 레벨 20 전직 시험, 특성 재조정, 유대 운용 선택, 정화 소모품 제작.
- **선택·다음 단서:** 공방 전체를 고발할지 관련 기술자 명단을 먼저 확보할지 선택. 고발은 조사가 빨라지지만 지원 장인이 줄고, 명단 확보는 추가 임무와 증거가 생긴다. 양쪽 모두 계약 원문이 백지에 있음을 알아낸다.

### 4장 — 기록의 빈자리

- **지역·레벨 가설:** 백지 기록령, 25~32.
- **목표:** 단절년의 원문과 현재 계약의 차이를 증명한다.
- **주요 인물:** 유안, 여진, 온재, 먹나, 기록관 대표. 류담은 영구 고정 계획을 공개적으로 설명한다.
- **시작:** 납품 문서의 인증 번호가 존재하지 않는 기록판을 가리킨다.
- **전개:** 도자기 편지, 주민 구술, 과거 수리 기록을 비교하며 영물의 갱신 조항이 지워졌음을 확인한다.
- **절정:** 온재의 창고 파괴를 막으면서 억류된 우편사와 기록판을 구한다.
- **결과:** 강제 계약의 증거가 확보된다. 피해자들이 직접 증언하고 기록관은 인증 책임을 인정해야 한다.
- **대표 퀘스트 3개:** 「빈 항아리의 편지」 전달·봉인 퍼즐 / 「읽지 않을 편지」 잠입·계약 / 「검은 창고」 구조·증거 확보.
- **핵심 도전:** 온재의 연막과 자동 기록 방어기를 통과하는 다단계 구조전. 온재를 죽이는 것을 완료 조건으로 삼지 않는다.
- **개방:** 혈계/도구 운용 변형, 먹나 계약, 기록 기반 지역 특성 도안.
- **선택·다음 단서:** 원문을 먼저 공개할지 피해자 보호 이동을 먼저 할지 선택. 지원 관계와 추가 구조 임무가 달라진다. 류담이 유리해의 중앙 결 접속기에 표본을 모았다는 사실은 공통으로 확인된다.

### 5장 — 누구의 길을 잇는가

- **지역·레벨 가설:** 유리해 항맹과 이전 지역의 짧은 지원 임무, 33~40.
- **목표:** 대피로와 임시 수송망을 확보하고 강제 영구 계약을 정지한다.
- **주요 인물:** 류담, 세림, 눈솔, 빈 가지의 영물 대표, 이전 장에서 신뢰를 얻은 동료.
- **시작:** 중앙 결 접속기 가동으로 작은 항로들이 역류하며 배가 항구를 벗어나지 못한다.
- **전개:** 각 지역의 도구와 지원 인력으로 수동 운반로를 복구한다. 영물마다 새 계약의 조건을 협상한다.
- **절정:** 류담과의 전투에서는 결 접속기 세 갈래의 연결을 끊고, 이어 주민 구조와 수동 전환을 수행한다.
- **결과:** 지역별 동의 갱신과 공개 감사가 있는 새 통행약정이 성립한다. 류담은 구금되고 피해 복구가 시작된다. 선택에 따라 복구를 맡는 동료와 지역 장면이 달라진다.
- **대표 퀘스트 3개:** 「잘못 비춘 항구」 빛 퍼즐·눈솔 계약 / 「여섯 곳의 한 가지 약속」 협상·제작 / 「끊고 다시 잇기」 보스·구조.
- **보스:** 류담의 **결 접속 장구**. 표식 연결, 방향 방어, 이동하는 안전 공간을 사용한다. 마지막에는 부서지는 장치를 탈출하며 복구 지점을 지킨다.
- **개방:** 레벨 40 장비 완성 경로, 영물의 마지막 유대 이야기, 지역 복구 의뢰.
- **후속 단서:** 통행망 밖의 나라에서 독립적인 결 조작의 흔적이 발견된다. 현 갈등의 해결을 취소하거나 또 다른 숨은 조종자를 넣지는 않는다.

## 9. 첫 마을 퀘스트 5개

다섯 임무는 첫 시제품의 전체 퀘스트다. 정식 1장에서는 이 뒤에 조합 조사와 수련 임무를 추가할 수 있다. 완료 플래그와 보상은 중복 지급되지 않도록 한다. 실패는 해당 단계 재도전으로 처리하며 계약과 장비는 삭제하지 않는다.

### Q1. 물보다 먼저 도착해야

- **시작 NPC:** 교관 단우. **목적:** 교체용 부품을 수문지기에게 전달.
- **장소:** 이음터 → 갈대둑 필드 입구.
- **진행:** 단우와 대화 → 표시된 부품 상자 받기 → 이동 안내 통과 → 철부리새 2마리의 공격 예고를 피하며 길 통과 → 수문지기에게 상호작용으로 전달.
- **성공:** 부품 전달. 전투는 처치하거나 안전하게 우회해도 됨.
- **실패:** 체력 0이면 필드 입구에서 재시작. 부품은 유지. 제한 시간 없음.
- **대사:** 단우: “빠르게 가라는 뜻이 아니야. 도착해야 한다는 뜻이지.”
- **보상 가설:** 레벨 2까지의 경험치, 재화 20, 첫 직업 기술 사선베기, 기본 장도.
- **연결:** 전달 직후 수문이 역류하고 매듭이 Q2를 요청한다.

### Q2. 젖은 둑의 작은 발

- **시작 NPC:** 매듭. **목적:** 안전한 우회로를 만들고 도톰의 둥지 이동.
- **장소:** 갈대둑의 젖은 나무 발판.
- **진행:** 느슨한 줄 2곳 조사 → 덩굴딱정벌레 2마리의 돌진을 피하거나 제압 → 지급된 밧줄로 고정점 설치 → 영물을 쫓지 않고 둥지 이동 경로 확보 → 도톰을 따라 안전한 둑에 도착.
- **성공:** 둥지와 귀환 경로 확인, 계약 대화 완료.
- **실패:** 발판 붕괴 시 가까운 둑에서 재시작. 도톰에게 다가가 놀라게 하면 잠시 숨고 다시 접근 가능. 영구 실패 없음.
- **대사:** 매듭: “잡으려 하지 마. 돌아갈 곳부터 만들어줘.”
- **보상 가설:** 도톰 계약, 영물 활성 1칸, 레벨 3 경험치, 수초섬유 3.
- **연결:** 동행 도톰이 수문 아래의 안전한 발판을 표시해 Q3 개방.

### Q3. 마지막 한 걸음

- **시작 NPC:** 도톰의 행동 표식과 수문지기 하온. **목적:** 끊긴 점검로를 건너 수문 압력 해제.
- **장소:** 갈대둑의 좁은 점검 틈. 일반 회피로는 못 넘지만 도톰의 추가 한 걸음으로 가능한 폭.
- **진행:** 동행 상태에서 안전 발판 확인 → 변신 초상화 누르기 → 신발 무늬와 회피 변화를 확인 → 회피로 틈 건너기 → 녹슨 순찰기의 직선 공격을 피함 → 수문 손잡이 돌리기.
- **성공:** 압력 해제. 동행 탐지와 장비 이동 효과를 각각 한 번 사용한 기록 확인.
- **실패:** 틈에 떨어지면 출발 발판 복귀. 연습 구간에 한해 결력 즉시 회복, 전투 구간부터 정상 회복 적용. 무한 추락 피해 없음.
- **대사:** 하온: “네가 한 걸음 더 간 덕에, 아래 마을이 숨을 쉬겠구나.”
- **보상 가설:** 레벨 4 경험치, 두 번째 기술 되받기, 하천광 2, 물길 장도 도안.
- **연결:** 압력이 내려가며 정상 부품에 덧씌워진 고리가 드러나 Q4로 연결. 첫 15분은 여기까지를 목표로 한다.

### Q4. 방앗간의 헐거운 이음

- **시작 NPC:** 도겸. **목적:** 줄비와 함께 부품을 수선하고 첫 장비 제작·강화.
- **장소:** 마을 작업장과 갈대둑 방앗간 앞방.
- **진행:** Q3 도안을 작업장에 제출하며 제작 지원금 50과 하천광 2 받기 → Q2·Q3의 재료로 물길 장도 제작 → 방앗간 앞방의 걸린 고리 조사 → 도톰을 쉬게 하고 줄비를 임시 동행 → 줄비가 표시한 연결쇠 풀기 → 안전한 손잡이 제작으로 계약 → 줄비 무기 변신 체험 → 지원 재료로 장도 +1 강화. 도안 제출 지원금은 한 번만 지급하며, 이 퀘스트에서 손잡이 수선은 무료 상호작용으로 처리한다.
- **성공:** 연결쇠 복구, 줄비 계약, 장도 제작과 +1 강화. 장비 화면은 짧은 한 화면 안내만 사용.
- **실패:** 재료를 다른 허용 제작에 쓴 경우 퀘스트 전용 재료를 다시 확보하는 표시된 상호작용 제공. 계약 대화는 다시 시작 가능. 저장 불러오기 후 제작 완료를 중복 요구하지 않음.
- **대사:** 도겸: “잘 만든 도구는 힘을 더하지. 나쁜 고리는 누구의 힘인지부터 빼앗고.”
- **보상 가설:** 줄비 계약, 장도 +1, 다음 강화 재료, 레벨 5 경험치. 현재 활성 칸은 여전히 1개라 도톰 또는 줄비 중 선택.
- **연결:** 줄비가 고리의 긴 연결선을 찾아 방앗간 아래 Q5 입구 개방.

### Q5. 물을 돌려놓는 손

- **시작 NPC:** 단우. **목적:** 방앗간 아래 정비기를 멈추고 고립 노동자 구조.
- **장소:** 물레방아 아래 짧은 던전.
- **진행:** 활성 영물 선택 안내 → 일반 적이 있는 첫 방 통과 → 물레의 두 손잡이를 맞춰 배수 → 노동자에게 안전 통로 안내 → 거름집게와 전투 → 집게의 직선 공격을 회피하고 공격 → 물길 방출 때 수문 손잡이로 안전 지대 확보 → 장치 정지 후 계약 고리 회수 → 조합 또는 주민 공동 보관 선택.
- **성공:** 노동자 생존, 정비기 정지, 고리 회수. 도톰과 줄비 양쪽으로 완수 가능한 일반 회피 거리와 보스 타이밍을 제공.
- **실패:** 플레이어 체력 0 또는 노동자 체력 0이면 현재 방의 체크포인트에서 재시작. 보스 재시도 시 노동자를 안전한 대기 위치로 되돌림. 이야기 선택 전에는 결과를 확정하지 않음.
- **대사:** 단우: “오늘 네 임무는 기계를 이기는 게 아니야. 모두를 데리고 돌아오는 거야.”
- **보상 가설:** 레벨 6~8까지 필요한 경험치의 일부, 재화 60, 확정 조율 부품, 첫 혈계/도구 수련권. 시제품에서는 수련권의 설명만 제공하고 별도 수련 퀘스트는 구현하지 않음.
- **연결:** 사다리령 납품 인장과 첫 여행 임무를 보여준다. 시제품은 여행 준비 장면에서 종료.

### 검증 계획과 초기 성공 기준

아래는 앞으로 수행할 플레이 테스트 계획이다. 아직 테스트를 실행하거나 목표 달성을 확인하지 않았다.

| 검증할 것 | 관찰 방법 | 초기 기준 가설 |
| --- | --- | --- |
| 한 손가락씩 이동·회피·스킬 조작이 가능한가 | 실제 휴대폰에서 오입력과 버튼 가림 기록 | 5명 중 4명이 추가 설명 없이 Q1 완수 |
| 동행/장비의 차이를 이해하는가 | Q3 뒤 각 형태의 이점을 본인 말로 설명 | 5명 중 4명이 두 형태를 구분하고 Q3 자력 완수 |
| 영물이 숫자 이상의 재미를 주는가 | 도톰/줄비로 같은 전투 재도전, 선택 이유 질문 | 서로 다른 상황적 선택 이유가 관찰됨. 전원이 같은 영물만 쓰면 효과 수정 |
| 전투에서 직접 행동이 의미 있는가 | 첫 보스에서 회피·반격·수문 사용 기록 | 공격 버튼만으로 버티는 전략이 가장 쉬운 방법이 되지 않음 |
| 제작으로 달라진 점을 느끼는가 | 제작 전후 짧은 동일 전투와 설명 질문 | 장도 특성 또는 영물 조합의 차이를 인지 |
| 다음 여행에 관심이 생기는가 | 종료 후 기억에 남은 인물과 해결하고 싶은 질문 확인 | 이야기 인물 또는 계약 고리에 대한 구체적 관심이 나타남 |
| 저장이 진행을 보존하는가 | Q3·Q4·보스 재시도 중 종료/재접속 | 보상 중복, 계약 소실, 제작 단계 잠금이 발생하지 않음 |

개발은 이동·전투 → 영물 두 상태 → Q1~Q3 → 제작과 줄비 → 던전·Q5 → 저장과 실제 휴대폰 점검 순서로 진행하는 기본안을 둔다. 아트는 먼저 크기와 공격 예고를 읽을 수 있는 임시 스프라이트로 검증한다.

## 12. 기존 작품과 닮을 위험이 있는 요소와 수정 방향

| 위험 요소 | 이 기획의 구분 방식 | 후속 창작 검토 |
| --- | --- | --- |
| 닌자와 혈족이라는 장르 조합 | 민간 구조·물류 조합, 물질에 작용하는 결, 혈계와 직업의 분리 | 복장·상징·능력 연출이 특정 작품을 직접 떠올리게 하는지 확인 |
| 동물 동료의 계약 | 작은 영물의 장비 변신과 상호 약속이 중심 | 대표 소환 동물의 외형·성격·대사 패턴을 대응시키지 않음 |
| 나라를 이동하는 영웅 서사 | 수로·통행·계약 갱신이라는 생활 문제에서 확장 | 유사한 나라 수보다 권력 구조와 사건 연결의 실질적 유사성 검토 |
| 혈계에 따른 특수 능력 | 감각과 실제 매질, 명시적인 물리적 제약 | 눈·문양·특정 자세 중심의 유명한 연출을 차용하지 않음 |
| 비밀을 감춘 과거의 협정 | 물류 약정의 숨겨진 동의 조항과 현재 피해 | 기존 작품의 반전 순서나 인물 역할 관계를 재현하지 않음 |
| 여러 동료의 이야기가 합류하는 결말 | 각자가 익힌 구조·기록·정비 기술이 복구에 기여 | 영웅 팀의 상징, 대사, 집결 구도를 대응시키지 않음 |

기획상의 구분은 법적 안전성을 보증하지 않는다. 가제·인물명·영물명·최종 아트·상업 출시 소재는 별도 검토 대상으로 남긴다. 참고 작품을 직접 인용하는 대사와 팬서비스 요소는 사용하지 않는다.
