# 결을 잇는 자 (가제)

장비로 변신하는 영물과 계약한 수습 닌자의 모바일 2D 액션 RPG.

- 기획서: [docs/game-design-v0.1.md](docs/game-design-v0.1.md)
- 게임 프로젝트: [game/](game/) — Godot **4.7.2** (개발·검증 기준), 세로 화면(720×1280), GL Compatibility 렌더러

## 공동 작업

- 작업 기준: [CLAUDE.md](CLAUDE.md)
- 구현 검토·우선순위·검증 증거: [docs/project-status.md](docs/project-status.md)
- 마법 교육원 분위기의 아트·UI 명세: [docs/art-direction-v0.1.md](docs/art-direction-v0.1.md)

Codex는 총괄·디자인, Claude는 Godot 구현을 담당한다. 개발 PC의 실제 엔진은 4.7.2.stable.official.ed1daf0bf이다. Codex 클라우드의 4.6.3에서도 `6a77e3e`의 **158개 점검과 Q4 조기/정상 강화 재현**이 통과했다. [최신 Q5 검토](docs/reviews/q5-review-2026-10-11.md)에 보스·퍼즐·선택·끝 카드·호위 보완을 기록했다.

교육원 [첫 아트 자산과 적용 지침](game/assets/README.md)을 제공했다. 자산 준비가 끝났고 게임 적용·재검증은 대기 중이다. 저장·첫 Android APK는 [인수 기준](docs/save-and-android-v0.1.md)을 따른다. 아직 실제 휴대폰 검증은 하지 않았다.

## 실행

Godot 4.7.2에서 **프로젝트 가져오기 → `game/project.godot`** 선택 후 실행(F5).

| 조작 | 휴대폰 | PC 테스트 |
| --- | --- | --- |
| 이동 | 왼쪽 아래를 누른 채 끌기 | WASD / 방향키 |
| 회피 | [회피] | Space |
| 사선베기 (Q1 보상) | [사선베기] | Q |
| 되받기 (Q3 보상) | [되받기] | F |
| 영물 동행 ↔ 장비 (도톰 신발 / 줄비 검) | 아래쪽 초상화 누르기 | R |
| 활성 영물 교체 (전투 밖) | 초상화 길게 누르기 | T |
| 목표·장비·재료 펼치기 | 상단 목표 줄 누르기 | Tab |
| 작업대 제작·강화 | [작업] → 목록의 버튼 | E → 1, 2 |
| 대화·줍기 / 대사 넘기기 | [대화] 버튼 / 화면 터치 | E |

기본 공격은 사거리 안의 적에게 자동으로 나간다. 도톰 신발은 회피가 틈 위나 적 근처에서 끝날 때 한 걸음 더 내딛는다 (결력 10, 8초 대기). 전투 중 변신은 2초 준비가 필요하고 맞으면 끊긴다.

## 자동 점검

```
Godot_v4.7.2-stable_win64_console.exe --headless --path game -- --autotest
```

Q1 22 · Q2 21 · Q3 25 · 영물 규칙 11 · Q4 31 · HUD 8 · Codex 재현 8 · Q5 35, 모두 161개 항목을 확인하고, 모두 통과하면 종료 코드 0을 돌려준다. `-- --autotest --q1`을 쓰면 Q1 22개만 점검한다. 예고·회피·피격, 발판 붕괴와 재시작, 도톰 접근·계약, 동행 탐지, 변신, 틈 건너기, 보상 중복 방지까지 포함한다. 코드는 [game/scripts/devtools.gd](game/scripts/devtools.gd)에 있다.

스크린샷: `-- --shot=경로.png --scenario=이름` (start, info, dialogue, aim, reward, q2_ropes, q2_calm, q2_follow, q3_marked, q3_shoe, q3_patrol, q3_done, q3_preview, q4_craft, q4_hooks, q4_wave, q4_done, q5_choice, q5_drain, q5_escort, q5_claw, q5_release, q5_end)

## 진행 상황

기획서 11장의 개발 순서를 따른다.

- [x] 이동·전투: 이동 패드, 회피(무적 시간), 자동 기본 공격, 결력, 사선베기
- [x] 철부리새: 직선 급습 예고 → 급강하 → 휘청(반격 기회) → 복귀
- [x] Q1 「물보다 먼저 도착해야」: 단우 → 부품 상자 → 갈대둑 → 하온 전달 → 수문 역류 → 매듭의 Q2 요청
- [x] 영물 두 상태: 도톰 동행(숨은 발판 탐지, 돌진 경고) ↔ 신발(이동속도 +5%, 추가 한 걸음)
- [x] Q2 「젖은 둑의 작은 발」: 느슨한 줄 조사 → 덩굴딱정벌레 → 고정점 설치 → 도톰에게 조용히 다가가기 → 따라가기 → 계약
- [x] Q3 「마지막 한 걸음」: 하온 → 동행 탐지(잎 표시) → 신발 변신 → 틈 건너기 → 녹슨 순찰기 → 압력 해제 → 되받기
- [ ] 첫 화면 이름·외형 선택
- [x] 상단 HUD 정리 (상시 정보 160px, 목표 한 줄·펼치기, 작은 안내 띠, 대사 길이에 맞는 창, 영물 초상화 아래쪽 가운데)
- [x] 제작·강화와 줄비, Q4 「방앗간의 헐거운 이음」: 도안 제출 → 물길 장도 제작 → 줄비 임시 동행·연결쇠 → 무료 손잡이 수선·계약 → 검 파동 → +1 확정 강화 → Q5 입구
- [x] 물레방아 던전·거름집게·Q5 「물을 돌려놓는 손」: 영물 선택 → 1방 → 물레 손잡이 배수 → 정비공 구조·안내 → 거름집게(직선 집게·바닥 쓸기·물길 방출, 수문으로 안전 지대) → 고리 회수와 보관 선택 → 사다리령 인장, 여행 준비 장면에서 끝
- [ ] 로컬 저장, 실제 휴대폰 점검 (Android 내보내기)

아트는 모두 코드로 그린 임시 도형이다. 수치는 기획서의 초기 가설이며 플레이 테스트로 조정한다.
