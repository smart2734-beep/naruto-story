# 결을 잇는 자 (가제)

장비로 변신하는 영물과 계약한 수습 닌자의 모바일 2D 액션 RPG.

- 기획서: [docs/game-design-v0.1.md](docs/game-design-v0.1.md)
- 게임 프로젝트: [game/](game/) — Godot 4.7, 세로 화면(720×1280), GL Compatibility 렌더러

## 실행

Godot 4.7에서 **프로젝트 가져오기 → `game/project.godot`** 선택 후 실행(F5).

| 조작 | 휴대폰 | PC 테스트 |
| --- | --- | --- |
| 이동 | 왼쪽 아래를 누른 채 끌기 | WASD / 방향키 |
| 회피 | [회피] | Space |
| 사선베기 (Q1 보상) | [사선베기] | Q |
| 대화·줍기 / 대사 넘기기 | [대화] 버튼 / 화면 터치 | E |

기본 공격은 사거리 안의 적에게 자동으로 나간다.

## 자동 점검

```
Godot_v4.7.2-stable_win64_console.exe --headless --path game -- --autotest
```

Q1 전체 흐름(대화 → 상자 → 입구 → 철부리새 예고·회피·처치 → 쓰러짐 재시작 → 전달·보상 → 수문 역류 → 매듭)을 22개 항목으로 확인하고, 모두 통과하면 종료 코드 0을 돌려준다.

스크린샷: `-- --shot=경로.png --scenario=start|dialogue|aim|reward`

## 진행 상황

기획서 11장의 개발 순서를 따른다.

- [x] 이동·전투: 이동 패드, 회피(무적 시간), 자동 기본 공격, 결력, 사선베기
- [x] 철부리새: 직선 급습 예고 → 급강하 → 휘청(반격 기회) → 복귀
- [x] Q1 「물보다 먼저 도착해야」: 단우 → 부품 상자 → 갈대둑 → 하온 전달 → 수문 역류 → 매듭의 Q2 요청
- [ ] 영물 두 상태 (도톰 동행/신발 전환)
- [ ] Q2·Q3 (덩굴딱정벌레, 녹슨 순찰기, 끊긴 점검로)
- [ ] 제작·강화와 줄비, Q4
- [ ] 물레방아 던전·거름집게·Q5
- [ ] 로컬 저장, 실제 휴대폰 점검 (Android 내보내기)

아트는 모두 코드로 그린 임시 도형이다. 수치는 기획서의 초기 가설이며 플레이 테스트로 조정한다.
